Tracker Guide & Privacy Information

1. Expected File Format

The dashboard accepts plain-text CSV files (.csv) or Excel spreadsheets (.xlsx / .xls). Your file must include a header row with the following column names (order is flexible, case-insensitive):

Date, Billable Hours, Pro Bono Hours, Non-Billable Hours
  • Date: Acceptable as YYYY-MM-DD or MM/DD/YYYY.
  • Numeric Hours: Decimal format (e.g. 7.5, 2.0). Days without entries are assumed to be 0.0 hours.
  • Cycle Range: The dashboard expects dates starting June 1 of the billing year through May 31.

2. Privacy Certification & Data Safety

100% Client-Side Execution: Your uploaded files, time entries, hours, and entered salary figures are processed exclusively in memory within your web browser using HTML5 FileReaders.

Zero Server Storage: No data is transmitted to an external server, backend database, cloud storage, or third party. Refreshing or closing the tab destroys all parsed data from memory.
